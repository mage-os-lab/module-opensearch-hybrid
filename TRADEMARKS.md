# Trademarks and release naming

`Mage-OS OpenSearch Hybrid`, `MageOS_OpenSearchHybrid`, and `mage-os/module-opensearch-hybrid` are working release identities while this module is developed inside the private evidence repository. Their presence does not imply endorsement, sponsorship, or affiliation with the Mage-OS Association, the OpenSearch Project, The Linux Foundation, Adobe, or Magento.

## Publication gate

The Mage-OS Terms of Use permit truthful compatibility references but prohibit using `Mage-OS` in a product name without permission. Public repository creation, package publication, a tag, or a release under the current product, component, or Composer identity therefore requires one of the following recorded outcomes:

1. Mage-OS Association approval for the current naming and destination.
2. Adoption into an official Mage-OS namespace whose maintainers confirm that use.
3. A reviewed rename that removes the Mage-OS mark from the product and package identity before publication.

This gate is independent from technical acceptance. Do not infer Mage-OS Association approval from local development, compatibility, a contribution proposal, or silence.

## OpenSearch

`OpenSearch` is used in its exact word-mark form to identify the software this module works with. The module does not redistribute a modified OpenSearch distribution, use an OpenSearch logo, or claim OpenSearch Project affiliation. Any public name must retain a clear source identifier, keep the OpenSearch mark no more prominent than that identifier, and comply with the [OpenSearch Trademark Policy](https://opensearch.org/trademark-brand-policy/).
